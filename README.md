# NixOS-KodNovaOS
"Personal NixOS ecosystem featuring Flakes, Ephemeral Root (Impermanence), and custom Nix modules. A fully reproducible, multi-host configuration for workstations and servers."

## The Dendritic Pattern
Structured around [the Dendritic Pattern](https://github.com/mightyiam/dendritic)

A modular approach where each host is built by composing standalone modules.

Adding a new machine is as simple as declaring what it should be. [example](https://github.com/KodNova/NixOS-KodNovaOS/blob/main/modules/fleet.nix)
